diffsplainer

Diff explanations for GitHub pull requests, powered by Claude Code.

Open a PR and the app shows its diff split into logical chunks on the right. On the left, next to each chunk, is Claude's explanation of what the change does, why it's made, and anything worth checking.

Run

Requirements: Python 3.11+, uv, and the Claude Code CLI (claude), logged in.

uvx diffsplainer

Then open http://localhost:3000.

Private repos need you to be logged in with the GitHub CLI (gh auth login), or to set GITHUB_TOKEN. If you log in with gh after starting the app, restart it.

Open a PR in any of these ways:

  • pass the PR URL when you start the app, which opens it in your browser: uvx diffsplainer https://github.com/owner/repo/pull/123
  • paste the PR URL into the address field, or
  • swap github.com for the app's host in the browser address bar: http://localhost:3000/owner/repo/pull/123

To open any GitHub PR with one click, drag the Diffsplain link from the start page to your bookmarks bar, then click it on a PR page.

The address bar always shows the PR you're reviewing, so links can be shared. To change how many related PRs Claude reads, add ?prs=N (0–10, default 3) to the address.

Review unpushed commits

To review commits that an agent made and has not pushed, run the app inside the repository, or give it the path:

uvx diffsplainer --local
uvx diffsplainer --local path/to/repo

The page lists the commits after the branch's upstream (with no upstream, after the point where the branch left the default branch) and shows them as one diff, with an explanation next to each chunk. When the repository's origin is on GitHub, the app reads the earlier merged PRs that changed the same files from GitHub, so Claude can use their reasons. It never writes to GitHub, and it never changes the repository's files, index or branches.

The page opens with the agent's summary of the work (a title, the ticket and a short description) when the agent has written one, and Claude reads it with the commit messages. When the branch has a plan file (approach/<branch>.md in the repository's git directory, or the file the agent names in its summary), Claude reads that too, and the context panel names it. The overview lists where the agent's summary or the commits differ from the plan, or where the commits do not support the summary when there is no plan.

To review, click Request changes on a chunk and say what to change. To ask about something you are unsure of, select text in a chunk's diff or explanation. Explain shows what a term means, and Comment adds your question to the review. The app saves your comments in diffsplainer/review.json in the repository's git directory, and the agent reads that file (see skill/diffsplainer-review) to answer with fixup commits and replies. To comment on the work as a whole, type in the General comment box above the button at the end of the review; it counts as one comment when you send. Click Resolve on an entry when the answer is enough. The buttons at the end of the review end the round. While comments are open, Send N comments to agent sends them. The page then checks every 5 seconds until the agent has replied to each comment or you have resolved it, and then shows the agent's fixup commits and replies. If the page does not have focus then, the tab title starts with ● until you return to it. When none is open, Approve approves every commit shown, and Approve and push also lets the agent push them without asking you again, once its checks pass. Before it pushes, the agent squashes its fixup commits, so the pushed commits can have new hashes; it never force-pushes. The agent does not push a branch that looks like it deploys: the default branch, a protected branch, a branch that a GitHub Actions workflow runs on push, or a branch with a deploy name such as staging or one that ends in -built. To add branches to that list, put one name per line in info/deploy-branches in the repository's git directory. The next run then shows only the commits made after that point, plus the entries that are still open.

How it works

The app fetches the PR from GitHub and splits each file's diff into chunks. Claude Code explains each chunk, and the explanation appears next to the chunk as soon as it is ready.

Claude also gets the PR description, the project's instruction files (such as CLAUDE.md and AGENTS.md) and a few earlier merged PRs that touched the same files. The "Context given to Claude" panel lists the ones it used.

The app runs Claude Code without your own MCP servers, hooks, slash commands and CLAUDE.md, so each call stays small. Closing or reloading the page stops the Claude calls it started.

To look up a word or phrase in an explanation, select it and click Explain. A popup shows what it means in general and what it does in this PR.

Opening the same PR again reuses the explanations while its commits stay the same. The app drops them when it restarts, or when it makes room for newer PRs (it keeps 50). Editing the PR title or description does not refresh them.

Code in the diff is syntax-highlighted for common languages, chosen by file extension.

PRs over 1,000 changed lines show the diff without explanations. Set MAX_CHANGED_LINES to change the limit. Lockfiles such as package-lock.json and composer.lock (and, in a local review, files marked linguist-generated in .gitattributes) show collapsed, are not explained and do not count toward the limit.

Configuration

| Env var | Default | Purpose | | --- | --- | --- | | PORT | 3000 | HTTP port. The app listens on 127.0.0.1 only. | | GITHUB_TOKEN / GH_TOKEN | GitHub CLI token | GitHub API auth | | GITHUB_API | https://api.github.com | API base URL (for GitHub Enterprise) | | CLAUDE_BIN | claude | Path to the Claude Code CLI | | CLAUDE_MODEL | sonnet | Model passed to --model. The app ignores the model set in your Claude Code settings. | | CLAUDE_CONCURRENCY | 6 | Parallel Claude calls | | CLAUDE_TIMEOUT_MS | 240000 | Timeout for each Claude call | | MAX_CHANGED_LINES | 1000 | Largest PR (additions plus deletions, not counting generated files) that gets explanations |

The app uses only the Python standard library. The browser UI is plain HTML/CSS/JS in src/diffsplainer/static/.

Development

To run the app from a clone of the repository:

git clone https://github.com/svandragt/diffsplainer
cd diffsplainer
uv run diffsplainer            # http://localhost:3000

Without uv: PYTHONPATH=src python -m diffsplainer.
